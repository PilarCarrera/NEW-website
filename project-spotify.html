Spotify Magical Redesign

I redesigned Spotify with a playful visual direction while preserving essential product flows. The concept keeps core functionality intact, including playlist creation, song management, and search, and was implemented as a working front-end prototype.

UI/UX Redesign Front-End Development Magical Vibes

Project Snapshot

Role: UI/UX Designer and Front-End Developer

Team: Individual contributor

Timeline: 1 week

Context

This personal concept explores how a mainstream music interface could shift toward a lighter, more expressive visual language while remaining usable and familiar.

My Role

I owned the full process from UI/UX concept design in Figma to front-end implementation, delivering an interactive prototype rather than static mockups. I also integrated the Spotify API to support realistic data and interaction flows.

Process

I defined the visual concept, mapped key listening workflows, designed high-fidelity screens, and implemented interactions in code to validate both look and usability.

Outcome

The final prototype includes 4 core screens and complete flows for search, playlist creation, and song management, proving the concept can remain expressive without losing usability.

Tech Stack

Figma, HTML, CSS, TypeScript, Spotify Web API.
