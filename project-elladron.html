Fanmade Musical Website

El Ladron del Rayo

I designed and developed this website for a fanmade musical adaptation of El Ladron del Rayo. I volunteered to create it at no cost, motivated by a long-standing personal connection to the books and a desire to support the project with professional UI/UX and front-end work.

UI/UX Design Front-End Development Fan Project

Project Snapshot

Role: UI/UX Designer and Front-End Developer

Team: Individual contributor

Timeline: 2 months total; design was completed in 1 week, with extended delivery due to slow client feedback cycles

Context

This was developed in Madrid for a local fanmade musical production. Because the production and audience are Spanish-speaking, the website content is presented in Spanish.

My Role

I owned the project end to end: UX structure, visual direction, responsive UI design, and front-end implementation, from concept through final delivery.

Process

I defined the information architecture for a one-page scrolling experience, designed and implemented it for both mobile and desktop, and iterated content presentation in Spanish to match the production context and audience.

Outcome

Delivered a complete Spanish-language one-page website, fully implemented for both desktop and mobile. The project includes additional sections beyond the screenshots shown here, but only a subset is displayed in this portfolio.

Tech Stack

Figma, HTML, CSS, JavaScript, responsive UI implementation.
